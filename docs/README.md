## Документация шаблона frontend-kit

Проект собран на шаблоне frontend-kit (папка `kit/`). Ниже — его общая
документация.

Шаблон для фриланс-проектов: общий **кит** (JS-модули, SCSS, React-хуки, формы, dev-инструменты)
и четыре **стартера**: вёрстка (Vite + HTML + JS), React, React + TypeScript, Astro (мультиязычные сайты).

## Главные принципы

1. **HTML говорит, что на странице.** `data-module="accordion"` — и блок ожил. Убрали блок —
   код не запустится.
2. **Каждый модуль убирает за собой.** `init(el, ctx) → { destroy }`. Поэтому модули работают
   и в многостраничной вёрстке, и в React, и с подгружаемым контентом.
3. **Один источник правды.** Брейкпоинты — в SCSS (JS читает их оттуда), правила формы — в схеме,
   версии пакетов — в package.json шаблона.
4. **Ошибка должна быть понятной.** Опечатка в имени модуля, цвета, слоя z-index, брейкпоинта,
   схемы — сообщение по-русски с подсказкой, а не молчаливо сломанная страница.
5. **Dev-инструменты не попадают в прод** — и это проверяется при сборке.
