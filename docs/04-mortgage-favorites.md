# 04. Ипотека, избранное, запись на показ

## Самый маленький пример: платёж по ипотеке

```ts
function monthly(loan: number, ratePercent: number, years: number) {
  const r = ratePercent / 12 / 100        // ставка в месяц: 6% годовых → 0.005
  const n = years * 12                    // месяцев
  if (r === 0) return loan / n            // рассрочка: просто делим
  return (loan * r * (1 + r) ** n) / ((1 + r) ** n - 1)
}

monthly(6_000_000, 6, 20)   // ≈ 42 986 ₽
```

## Ипотечный калькулятор (`lib/mortgage.ts`, `modules/mortgage`)

Аннуитетный платёж — одинаковый каждый месяц:

```
платёж = кредит × r × (1 + r)ⁿ / ((1 + r)ⁿ − 1)
r — ставка в месяц (годовая / 12 / 100), n — число месяцев
```

При ставке 0 (рассрочка от застройщика) формула делит на ноль, поэтому
отдельная ветка: `кредит / n`. Рекомендуемый доход — платёж не больше 50 %.

Модуль следит за правилами программ: взнос не меньше минимального,
рассрочка — не дольше 2 лет. Числа «набегают» плавно (GSAP твинит число, а
`onUpdate` пишет его в текст); при «меньше движения» — сразу.

## Избранное (`modules/favorites`)

- Кнопки ♥ где угодно на странице, модуль ставится **один раз** на `<body>`
  и обслуживает клики **делегированием** — в том числе карточки, которые
  каталог дорисовал позже.
- Список хранится в localStorage и синхронизируется между вкладками
  (событие `storage`).
- Состояние кнопок — `aria-pressed` и подпись «В избранное» / «Убрать из
  избранного»: скринридер понимает, что это переключатель.

## Запись на показ

Диалог с формой; схема проверки зарегистрирована в `scripts/app.ts`
(`registerSchema('visit', …)`). Кнопка на странице квартиры передаёт в форму
её номер через `data-visit-flat`.

Бэкенда нет, поэтому отправка — демо: показываем уведомление «заявка
принята» и сбрасываем форму. Для настоящего сервера — убрать этот
обработчик и добавить форме `data-form-ajax` и `action`.

## Ошибки

> **Формула без ветки для ставки 0.** Деление на ноль — `NaN ₽` на экране для рассрочки.
>
> **Обработчик на каждую кнопку ♥.** Карточки, которые каталог дорисовал позже, остаются без
> обработчика. Делегирование на `<body>`.
>
> **♥ без `aria-pressed`.** Скринридер не знает, что это переключатель и в каком он состоянии.
>
> **Анимация числа при «меньше движения».** Длительность — 0.

## Попробуйте сами

1. Посчитайте вручную платёж: 6 000 000 ₽, 6 % годовых, 20 лет. Сверьте с калькулятором на сайте.
2. Выберите программу «Рассрочка» и потяните срок на 10 лет. Что произойдёт?
3. Добавьте квартиру в избранное в одной вкладке. Что увидите во второй?

<details>
<summary>Ответы</summary>

1. ≈ 42 986 ₽ (при цене, взносе и программе, дающих кредит 6 000 000 ₽).
2. Ползунок остановится на 2 годах: у рассрочки `max = 2`.
3. Счётчик и сердечки обновятся: модуль слушает событие `storage`.
