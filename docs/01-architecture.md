# 01. Архитектура «Сосен»

Сайт жилого комплекса на **Astro** + TypeScript, собранный на шаблоне
frontend-kit. Всё статическое: `astro build` выпускает готовые HTML-файлы —
главную, каталог, избранное и **270 страниц квартир**.

## Почему Astro

Сайт ЖК — это в основном контент: тексты, фото, характеристики, планировки.
Ему нужны быстрая первая загрузка и индексация поисковиками. Astro по
умолчанию **не отправляет в браузер JavaScript**: компоненты `.astro`
выполняются при сборке и превращаются в HTML. Интерактив (3D, фильтры,
калькулятор) подключается точечно.

## Папки

```
src/
  pages/            маршруты = файлы
    index.astro           главная
    flats/index.astro     каталог: фильтры, шахматка, список
    flats/[id].astro      страница квартиры ×270 (getStaticPaths)
    plans/[layout].svg.ts планировки как SVG-файлы
    favorites.astro, 404.astro
  components/       секции страниц (.astro): Hero, Chess, Mortgage…
  layouts/Base.astro  общий каркас: <head>, шапка, подвал
  data/             квартиры и данные проекта
  lib/              чистая логика: фильтры, ипотека, планировки, карточка
  modules/          интерактив по контракту кита: building3d, catalog, mortgage, favorites
  scripts/app.ts    запуск модулей на всех страницах
  styles/           SCSS
```

## Как оживает разметка

В `.astro` элемент помечается атрибутом:

```astro
<section data-module="catalog"> … </section>
```

`scripts/app.ts` запускает `createApp` кита: он находит все `[data-module]`
и вызывает соответствующий модуль `init(el) → { destroy }`. Тяжёлые модули
подключены **лениво**:

```ts
building3d: lazy(() => import('../modules/building3d/index')),
```

Код 3D-квартала (вместе с three.js ≈ 600 КБ) скачивается, только если на
странице есть `data-module="building3d"`, то есть только на главной.

## Данные

Квартиры в реальном проекте приходят из CRM застройщика. Здесь они
**генерируются** (`data/flats.ts`) — 3 башни × 15 жилых этажей × 6 квартир = 270.

Генератор случайных чисел — с «зерном» (mulberry32): одинаковое зерно даёт
одинаковую последовательность, поэтому квартиры **каждый раз одни и те же**.
Это важно: иначе при каждой сборке цены и статусы менялись бы, а ссылки на
квартиры вели бы на другие квартиры.

Хотите свои данные — замените `FLATS` на массив из JSON с теми же полями.

## Чистая логика отдельно

`lib/filters.ts`, `lib/mortgage.ts`, `lib/plan.ts` — функции без DOM. Их
вызывают и Astro при сборке, и модули в браузере, и тесты (199 тестов).
