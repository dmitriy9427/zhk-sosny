# 02. 3D-квартал на первом экране

Файлы: `src/modules/building3d/index.ts` (модуль), `scene.ts` (сцена three.js).

Три башни среди сосен у реки, вечерний свет. Наведение на башню — подсказка
с числом свободных квартир, клик — каталог этой башни.

## Самый маленький пример: вращающийся куб

```ts
import * as THREE from 'three'

const renderer = new THREE.WebGLRenderer()
renderer.setSize(400, 300)
document.body.append(renderer.domElement)

const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(50, 400 / 300, 0.1, 100)  // угол обзора, пропорции, ближе/дальше
camera.position.z = 5

const cube = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshNormalMaterial())
scene.add(cube)

renderer.setAnimationLoop(() => {
  cube.rotation.y += 0.01
  renderer.render(scene, camera)       // нарисовать кадр
})
```

Четыре сущности three.js: **рендерер** (рисует в `<canvas>`), **сцена** (что рисовать),
**камера** (откуда смотреть), **меш** = геометрия (форма) + материал (вид). Всё остальное в
квартале — те же четыре вещи, только их больше.

## Всё из кода, без моделей

| Объект | Как сделан |
| --- | --- |
| Башни | `BoxGeometry` + текстура фасада, нарисованная на canvas |
| Окна вечером | вторая canvas-текстура, где горит часть окон, — в `emissiveMap` |
| Сосны | `InstancedMesh`: 400 деревьев одним вызовом отрисовки |
| Река | плоскость с тёмным отражающим материалом |
| Свет | тёплый направленный «закат» + холодное небо (`HemisphereLight`) |

**Текстура на canvas.** Рисуем в обычном 2D-canvas сетку окон и
превращаем его в текстуру (`CanvasTexture`). Нет файлов для загрузки, а
расположение горящих окон задаёт генератор с зерном — одинаковое при
каждом открытии.

**`emissiveMap`** — карта свечения: окна светятся сами, без сотни
источников света (каждый источник — нагрузка на видеокарту).

**`InstancedMesh`** — один и тот же меш (сосна) рисуется 400 раз за один
вызов: видеокарте передаётся геометрия один раз и 400 матриц положения.
400 отдельных мешей дали бы 400 вызовов отрисовки — заметно медленнее.

## Какая башня под курсором — Raycaster

Из камеры через точку курсора «выпускается луч» (`Raycaster`), и three.js
находит, какие объекты он пересёк. Первая пересечённая башня подсвечивается,
рядом показывается подсказка «Башня 2 — 52 свободные квартиры».

## Бережём ресурсы

- **Ленивая загрузка:** `await import('./scene')` — three.js грузится,
  только когда модуль запущен, а страница уже показана.
- **Кадры только на экране:** `onViewport` добавляет функцию отрисовки в
  `gsap.ticker`, когда блок виден, и убирает, когда скрыт.
- **Плотность пикселей ≤ 1,75** — на ретина-экранах это почти вдвое меньше
  работы без видимой потери качества.
- **Без WebGL или при «меньше движения»** — остаётся CSS-картинка-заглушка.
- `ResizeObserver` подгоняет размер холста под блок.

## Камера

- **Прокрутка:** ScrollTrigger отдаёт прогресс 0…1, камера облетает квартал
  и поднимается.
- **Мышь:** лёгкий параллакс с инерцией — целевая точка (`tx/ty`) меняется
  сразу, а текущая (`x/y`) догоняет её на долю расстояния каждый кадр.
  Так движение плавное даже при резком рывке мыши.

## Ошибки

> **Рисовать кадры, когда блок за экраном.** Видеокарта работает впустую, ноутбук греется.
> Отрисовка только пока блок виден (`onViewport`).
>
> **Плотность пикселей как у экрана.** На ретине с `devicePixelRatio = 3` — в 9 раз больше пикселей,
> чем при 1. Ограничьте (здесь 1,75).
>
> **400 отдельных мешей.** 400 вызовов отрисовки. `InstancedMesh` — один.
>
> **Не освобождать ресурсы.** Геометрии, материалы и текстуры живут в памяти видеокарты, пока их не
> `dispose()`. Ушли со страницы — утечка.
>
> **Нет запасного пути.** Без WebGL сцена не создастся — нужна картинка-заглушка.

1. Поменяйте `COUNT = 400` на `4000`. Изменилась ли плавность? Почему почти нет?
2. Где задано, какие окна «горят», и почему каждый раз одни и те же?
3. Наведите курсор на башню. Как three.js понял, какая башня под мышью?

<details>
<summary>Ответы</summary>

1. Почти нет: `InstancedMesh` рисует все копии одним вызовом, видеокарте передаются только
   матрицы положения.
2. `facadeTexture(seed, lit)`: генератор с зерном `tower * 101` решает, какие окна горят.
3. Raycaster: луч из камеры через точку курсора, первый пересечённый меш башни — ответ; в его
