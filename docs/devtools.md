# Инструменты разработки

Всё в этом разделе работает **только в разработке** и не попадает к заказчику.

## Dev-панель

Кнопка ⚙ слева внизу или **Shift+Alt+K** в `npm run dev`.

| Инструмент   | Что делает                                                                 | Когда нужен                      |
| ------------ | -------------------------------------------------------------------------- | -------------------------------- |
| Сетка        | колонки макета поверх страницы (из `$grid-columns`, `--grid-gap`)          | сверка с макетом                 |
| Брейкпоинт   | «md · 834px» в углу                                                        | адаптив                          |
| FPS          | кадры в секунду и худший кадр; красный — меньше 50                         | тормозит анимация                |
| Контуры      | рамка у каждого блока                                                      | лишние отступы, вылеты           |
| Макет        | картинка макета поверх вёрстки, прозрачность, режим «разница»              | pixel perfect                    |
| Сдвиги (CLS) | в консоль — элементы, которые прыгают при загрузке                         | плохой Lighthouse                |
| Переполнение | список элементов, вылезающих за экран (клик — показать)                    | горизонтальный скролл на мобилке |
| Доступность  | img без alt, кнопки без подписи, поля без label, h1→h3, дубли id, нет lang | перед сдачей                     |
| Модули       | какие `data-module` на странице и запущены ли                              | «модуль не работает»             |

Состояние галочек запоминается между перезагрузками. Режим «разница» у макета: совпавшие
пиксели становятся чёрными — расхождения видно сразу.

Из консоли: `__kit` — приложение (`__kit.ctx.bus.emit(...)`, `__kit.mounted`),
`__KIT_DEVTOOLS__` — панель (`.set('grid', true)`, `.run('a11y')`).

## Как панель не попадает в прод

```js
if (import.meta.env.DEV) import('kit/devtools/index.js').then((m) => m.installDevtools())
```

При сборке условие становится `if (false)` и код вырезается. Страховка — плагин
`devtools-guard`: если метка панели всё-таки оказалась в файлах сборки, сборка падает с
объяснением.

## Vite-плагины (`kit/vite`)

```js
plugins: [...kit()] // vanilla
plugins: [react(), ...kit({ include: false, pages: false })] // React
```

### html-include

```html
<include src="header.html" title="Главная"></include>
```

В куске: `{{ title }}`, `{{ title | значение по умолчанию }}`. Вложенные include, переменные
родителя доступны детям. Ссылки на текущую страницу получают `aria-current="page"`.
Include внутри HTML-комментариев не разворачиваются (можно писать примеры).
Ошибки понятные: нет файла, цикл (a → b → a), нет `src`, путь за пределами `partials/`.

### pages

Все `.html` из корня проекта — страницы сборки. `pagesInput({ nested: true })` — и из подпапок.

### mock-api

`mocks/news/latest.js` отвечает на `/api/news/latest`:

```js
export const GET = ({ query }) => ({ body: [{ id: 1, title: 'Новость' }] })
export function POST({ body }) {
  if (!body.phone) return { status: 422, body: { errors: { phone: 'Укажите телефон' } } }
  return { body: { message: 'Принято' } }
}
```

Задержка ответа 400 мс (видно спиннеры, ловятся двойные клики): `mockApi({ delay: 0 })` — без неё.
Правки мока подхватываются без перезапуска.

Бэкенд уже есть и нужно ходить на него из dev — прокси вместо мока:

```js
// vite.config.js
server: { proxy: { '/api': 'https://dev.site.ru' } },
plugins: [...kit({ mocks: false })],
```

### devtools-guard

Описан выше. Отключать не нужно.

## Линтеры и форматирование

| Инструмент   | Конфиг                | Что ловит                                             |
| ------------ | --------------------- | ----------------------------------------------------- |
| ESLint       | `eslint.config.js`    | ошибки JS, правила хуков React, забытые `console.log` |
| Stylelint    | `stylelint.config.js` | ошибки SCSS, имена классов по БЭМ                     |
| Prettier     | `.prettierrc.json`    | единый стиль кода (кавычки, отступы, переносы)        |
| EditorConfig | `.editorconfig`       | отступы и переводы строк в любом редакторе            |

`npm run fix` — поправить всё, что можно автоматически.
В VS Code поставьте расширения ESLint, Stylelint, Prettier и включите «Format on Save».
