# 03. Каталог, шахматка и страницы квартир

## Фильтры в адресе (`lib/filters.ts`, `modules/catalog`)

```
/flats/?rooms=1,2&price=5000000-12000000&floor=5-16&tower=2&sort=price
```

1. При загрузке фильтры читаются из адреса и выставляются в форму.
2. Любое изменение формы → объект `Filters` → чистые функции фильтрации →
   новый адрес через `history.replaceState`.

`replaceState`, а не `pushState`: при движении ползунка цены адрес меняется
десятки раз, и каждая запись в истории сделала бы кнопку «Назад»
бесполезной. Ссылкой на подборку можно поделиться — фильтры восстановятся.

## Шахматка (`components/Chess.astro`)

Все квартиры по башням и этажам — классика сайтов застройщиков. Сетка
рисуется **при сборке** (Astro), в браузере модуль только переключает класс
`is-match`: подходящие под фильтр ячейки яркие, остальные приглушены. Цвет
ячейки — число комнат, проданные — серые. Каждая ячейка — ссылка на квартиру.

## Одна карточка для сервера и браузера (`lib/card.ts`)

Список под шахматкой рисует **браузер** (результат фильтра меняется), а на
странице квартиры блок «Похожие» рисует **Astro** при сборке. Чтобы карточка
везде выглядела одинаково, есть одна функция `cardHtml(flat)`, которая
возвращает HTML-строку. Astro вставляет её через `set:html`, модуль каталога —
через `innerHTML`. Данные только наши, не от пользователя, поэтому XSS нет.

Все квартиры передаются модулю в `<script type="application/json">` прямо в
разметке — без отдельного запроса. Список показывает первые 24, «Показать ещё»
добавляет следующие.

## 270 страниц квартир (`pages/flats/[id].astro`)

```ts
export function getStaticPaths() {
  return FLATS.map((flat) => ({ params: { id: flat.id }, props: { flat } }))
}
```

Astro вызывает `getStaticPaths` при сборке и делает отдельный HTML-файл на
каждую квартиру: свой адрес, `<title>`, описание для поисковиков. Никакого
сервера — 270 обычных файлов.

## Планировки кодом (`lib/plan.ts`)

Планировки по типу квартиры (студия, 1-, 2-, 3-комнатная) описаны как
прямоугольники комнат в «клетках» (1 клетка ≈ 10 см). Функция `planSvg`
рисует стены, комнаты с подписями и площадями, окна и двери.

Два способа использования:

- На странице квартиры SVG **встраивается** в HTML (с её точной площадью).
- Для карточек списка есть эндпоинт `pages/plans/[layout].svg.ts`: при сборке
  он превращается в четыре файла `/plans/studio.svg` … `/plans/three.svg`.
  Карточки ссылаются на них через `<img>` — браузер скачивает четыре файла и
  кеширует на все 270 карточек.
