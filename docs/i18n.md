# Языки (i18n)

## Два случая — два подхода

| Сайт (SEO важно)                                                            | Приложение, кабинет                   |
| --------------------------------------------------------------------------- | ------------------------------------- |
| У каждого языка свой адрес: `/`, `/en/`                                     | Язык меняется «на лету», адрес тот же |
| Стартер **astro** (встроенный роутинг языков) или отдельные HTML на vanilla | `setLocale('en')` + `data-i18n`       |
| Поисковик индексирует обе версии                                            | Поисковику видна одна версия          |
| Переключатель — ссылки `<a hreflang>`                                       | Переключатель — кнопки `data-lang`    |

Язык, переключённый скриптом, поисковик не видит, поэтому для сайтов — отдельные адреса.

## Ядро: kit/js/core/i18n.js

```js
import { t, addMessages, setLocale, getLocale } from 'kit/js/core/i18n.js'

addMessages('ru', {
  cart: { add: 'В корзину', items: { one: '{count} товар', few: '{count} товара', many: '{count} товаров' } },
})
addMessages('en', { cart: { add: 'Add to cart', items: { one: '{count} item', other: '{count} items' } } })

t('cart.add') // по языку <html lang>
t('cart.items', { count: 3 }) // «3 товара» / «3 items» — склонения через Intl.PluralRules
setLocale('en', { remember: true }) // сменить и запомнить выбор
```

Нет перевода — вернётся ключ (`cart.add`) и предупреждение в консоли в разработке: на странице
видно, что пропущено, а не пустое место. Нет ключа в текущем языке — берётся из русского.

## Перевод разметки

```html
<h1 data-i18n="hero.title">Заголовок</h1>
<!-- текст -->
<input data-i18n-attr="placeholder:search.ph, aria-label:search.label" />
<p data-i18n="cart.items" data-i18n-count="3">3 товара</p>
<p data-i18n-html="legal.consent">…</p>
<!-- с разметкой, только свой текст! -->
```

Исходный текст в HTML остаётся запасным (без JS, для поисковиков).

## Тексты кита

Все сообщения модулей (ошибки форм, «Ничего не найдено», подписи кнопок для скринридеров)
лежат в `kit/js/i18n/ru.js` и `en.js` под ключами `kit.*`. Модули сами говорят на языке
страницы. Новый язык — `addMessages('de', { kit: { … } })` с теми же ключами (скопируйте en.js).

## Astro

`src/i18n/ui.ts` — словари страниц с проверкой TypeScript (пропущенный ключ — ошибка сборки).
Страницы: `src/pages/…` — русские, `src/pages/en/…` — английские; общая разметка — в компонентах.
`<head>` сам добавляет `hreflang` и `canonical`, sitemap собирается для обоих языков.
