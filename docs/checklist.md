# Чек-лист перед сдачей

Пройдите сверху вниз. Большая часть проверяется за 15 минут, а ловит то, что заказчик
заметит в первый же день.

## Автоматически

- [ ] `npm run check` — без ошибок (линтеры, тесты, сборка).
- [ ] Lighthouse (Chrome DevTools → Lighthouse, мобильный режим) на главной и 1–2 внутренних:
      Performance ≥ 80, Accessibility ≥ 90, SEO ≥ 90.
- [ ] Dev-панель → **Доступность** и **Переполнение** на каждой странице — пусто.

## Адаптив

- [ ] Ширины 320, 375, 768, 1024, 1280, 1440, 1920 — нет горизонтального скролла, ничего не налезает.
- [ ] Реальный телефон (iOS Safari + Android Chrome): меню, модалки, формы, клавиатура не
      закрывает поле ввода, нет увеличения при фокусе.
- [ ] Альбомная ориентация телефона.

## Контент и SEO

- [ ] У каждой страницы свои `<title>` и `description`; один `<h1>`.
- [ ] Open Graph (картинка 1200×630) — ссылка красиво выглядит в Telegram/VK.
- [ ] favicon, `theme-color`.
- [ ] 404 — своя страница.
- [ ] `robots.txt`: на проде индексация ОТКРЫТА (`Allow: /`), sitemap.xml есть.
- [ ] Нет «Lorem ipsum», тестовых телефонов, ссылок `#`.

## Формы

- [ ] Каждая форма реально отправляется на бэкенд (не мок), приходит письмо/заявка.
- [ ] Ошибки показываются по-русски, под полем; после успеха — понятное сообщение.
- [ ] 152-ФЗ: согласие на обработку данных + ссылка на политику конфиденциальности.
- [ ] Цели аналитики (Метрика) на успешную отправку: событие `form:success`.

## Доступность

- [ ] Всё проходится с клавиатуры (Tab, Enter, Esc), фокус видно.
- [ ] Картинки с `alt`, иконки-кнопки с `aria-label`.
- [ ] Контраст текста (Lighthouse подсветит).
- [ ] Системная настройка «уменьшить движение» — анимации спокойные.

## Производительность

- [ ] Картинки сжаты (WebP/AVIF), с `width`/`height`, ниже первого экрана — `loading="lazy"`.
- [ ] Видео — `lazy-video`, с постером, лёгкая мобильная версия.
- [ ] Шрифты — только нужные начертания и кириллица+латиница.
- [ ] Dev-панели нет в проде (сборка упадёт, если есть).

## Браузеры

- [ ] Chrome, Safari (macOS и iOS), Firefox, Яндекс Браузер.
- [ ] Тёмная тема (если есть) — все блоки читаемы.

## Передача

- [ ] README проекта: как запустить, где что, куда подключён бэкенд.
- [ ] Доступы (хостинг, домен, Метрика) — у заказчика, а не только у вас.
