# Частые баги и как их чинить

Формат: **симптом → причина → решение**. Ищите по симптому (Ctrl+F: «прыгает», «не открывается», «404»…).
Пометка **[кит]** — уже исправлено в ките, описано, чтобы вы понимали, почему код написан именно так,
и не сломали это при правках.

## Установка и запуск

**`npm install` падает с ошибкой про engine / синтаксис.**
Старый Node. Нужен 20.19+ (`node -v`). Версия записана в `.nvmrc`: `nvm use`.

**`npm run dev`: «Port 5173 is already in use».**
Уже запущен другой проект. Закройте его или `npm run dev -- --port 5180`.

**Страница пустая, в консоли `Failed to resolve import "kit/..."`.**
Нет папки `kit/` рядом с `vite.config.js` или испорчен alias. В проекте должно быть
`resolve.alias.kit = …/kit`. Если копировали проект руками — верните `kit/` или пересоздайте
через `npm run create`.

**Правки в `partials/*.html` не видны.**
Плагин html-include перезагружает страницу сам **[кит]**. Если не помогло — проверьте, что файл
лежит именно в `partials/` (имя папки задаётся в `htmlInclude({ dir })`).

**Новая страница открывается в dev, а после сборки — 404.**
Без плагина `pages` Vite собирает только перечисленные страницы. **[кит]** — плагин собирает
все `.html` из корня. Страница во вложенной папке (`/blog/post.html`) — включите
`pagesInput({ nested: true })`.

## Сборка и деплой

**На хостинге белая страница, в консоли 404 на `/assets/...js`.**
Сайт лежит не в корне домена (`site.ru/promo/`, GitHub Pages). Соберите с базовым путём:
`BASE_URL=/promo/ npm run build`. Ссылки в HTML пишите относительными или через `/` с учётом base.

**React: после обновления страницы `/about` → 404.**
SPA: сервер ищет файл `about`, а его нет. Сервер должен отдавать `index.html` на любой путь —
настройки для nginx, Apache, Netlify, GitHub Pages в [deploy.md](deploy.md).

**Сборка падает: «Dev-инструменты попали в продакшн-сборку».**
Где-то `import 'kit/devtools'` без условия. Подключайте только так:

```js
if (import.meta.env.DEV) import('kit/devtools/index.js').then((m) => m.installDevtools())
```

Именно `import.meta.env.DEV` прямо в `if` — не в переменной (`const dev = …; if (dev)`), иначе
сборщик не сможет вырезать код. **[кит]** — проверку делает плагин `devtools-guard`.

**`import.meta.env.VITE_API_URL` = undefined.**
Переменная без префикса `VITE_` или файл назван не `.env`. После правки `.env` перезапустите
`npm run dev`. Помните: всё с `VITE_` видно в браузере — не храните там секреты.

**Заказчику отдали `dist/`, а у него «ничего не работает» при открытии `index.html` двойным кликом.**
Модули ES не грузятся с `file://`. Сайт нужно открывать через сервер (`npm run preview` или хостинг).

## SCSS

**`This module was already loaded, so it can't be configured using "with"`.**
Настройки кита (`@forward 'kit/scss/abstracts' with (...)`) подключились ПОСЛЕ того, как кто-то
уже загрузил кит без настроек. В `main.scss` первой строкой должно быть `@use 'abstracts';`,
второй — `@use 'kit/scss';`. В остальных файлах — только `@use 'abstracts' as *;`, никогда
`@use 'kit/scss/abstracts'` напрямую.

**`Undefined mixin` / `Undefined function rem`.**
В файле нет `@use 'abstracts' as *;`. В Sass модули не «видят» друг друга — каждый файл
подключает то, что использует.

**`Нет цвета «acent»` / `Нет слоя «modal»` / `Нет брейкпоинта «tablet»`.**
Опечатка или значение не добавлено в настройки. **[кит]** — функции `color()`, `z()`, `bp()`
специально падают с понятной ошибкой, а не выдают пустой CSS. Новый слой/цвет — в `_abstracts.scss`.

**Предупреждения `@import is deprecated`.**
Используйте `@use`/`@forward`. `@import` удалят в Dart Sass 3.

**На ширине ровно 768px (или 767.5px на Windows с масштабом 125%) ломается вёрстка.**
`max-width: 767px` и `min-width: 768px` оставляют щель в 1px для дробных ширин. **[кит]** —
`down()` вычитает 0.02px. Пишите медиазапросы только миксинами `up/down/between`.

**Брейкпоинт в JS не совпадает с CSS.**
Числа заданы в двух местах. **[кит]** — источник один: `$breakpoints` в SCSS → CSS-переменные
`--bp-*` → `getBreakpoints()` в JS. Меняйте только SCSS.

## Вёрстка и адаптив

**На телефоне страница «гуляет» влево-вправо (горизонтальный скролл).**
Что-то шире экрана: `width: 100vw` (включает полосу прокрутки), картинка без `max-width`,
длинное слово/ссылка, отрицательный margin, слайдер без `overflow: hidden`.
Найти виновника: dev-панель → **Переполнение** — покажет самый «глубокий» вылезающий элемент.
Не лечите `overflow-x: hidden` на `body` — это ломает `position: sticky`; чините причину
(или `overflow-x: clip` на конкретной секции).

**`position: fixed` элемент ведёт себя как absolute (меню высотой с шапку, модалка обрезана).**
У предка есть `transform`, `filter`, `backdrop-filter`, `perspective`, `will-change: transform`
или `contain`. Они делают предка «контейнером» для fixed-потомков. **[кит]** — размытие шапки
вынесено в `::before`. Решение в общем случае: вынести fixed-элемент из такого предка или
перенести эффект на псевдоэлемент.

**`position: sticky` не липнет.**
У предка `overflow: hidden/auto/scroll` (в т.ч. `overflow-x: hidden` на body), у самого
элемента нет `top`, или родитель по высоте равен элементу.

**Блок `height: 100vh` на iPhone уходит под панель браузера.**
`100vh` на мобильных = высота БЕЗ адресной строки. Используйте `100svh` (маленький экран)
или `100dvh` (меняется вместе с панелью). **[кит]** — так сделано в `body` и `.hero`.

**iPhone увеличивает страницу при фокусе на поле.**
Шрифт поля меньше 16px. **[кит]** — в reset на мобилке шрифт полей не меньше 16px.

**Hover «залипает» на телефоне после тапа.**
На тач-экране `:hover` срабатывает при тапе и не снимается. Пишите hover миксином
`@include hover { … }` — он работает только при наличии мыши.

**z-index: 9999 не помогает.**
Элементы в разных контекстах наложения (предок с `z-index` + `position`, `opacity < 1`,
`transform`…). Сравниваются контексты, а не числа. Все слои — через `z('header')` из карты
`$z-layers`; модалки — нативный `<dialog>` (верхний слой браузера, вне z-index вообще).

**Страница «прыгает» при открытии модалки/меню.**
Исчезла полоса прокрутки → контент сдвинулся на её ширину. **[кит]** — `lockScroll()`
компенсирует отступом `--scrollbar-width`, а `scrollbar-gutter: stable` резервирует место.

**Тексты в карточках разной длины — кнопки «пляшут» по высоте.**
Карточке `display: flex; flex-direction: column`, кнопке `margin-top: auto`.

**Swiper внутри grid/flex: слайдер шириной 0 (пустое место) или растягивает страницу на тысячи пикселей.**
У `.swiper` в CSS Swiper стоит `margin: auto`, а авто-отступы во flex/grid отключают
растягивание: ширина берётся «по содержимому». Плюс у элементов сетки `min-width: auto`.
**[кит]** — у `.swiper` стоят `width: 100%` и `min-width: 0`. Для своих каруселей — то же.

**Картинка в flex/grid вылезает или не сжимается.**
У flex/grid-элементов `min-width: auto` по умолчанию. Добавьте `min-width: 0` элементу.

## Модули (data-module)

**Модуль не работает, ошибок нет.**
Опечатка в имени. **[кит]** — в консоли будет «нет модуля «acordion». Доступны: …».
Нет предупреждения — проверьте, что модуль добавлен в реестр (`src/modules/index.js`).

**Модуль срабатывает дважды (аккордеон открывается и сразу закрывается).**
Модуль запущен два раза на одном элементе: повторный `mount()` после подгрузки контента,
два одинаковых обработчика. **[кит]** — реестр не запускает модуль дважды на элементе.
Если пишете обработчики вне модулей — используйте `createDisposer` и `destroy`.

**Подгруженный (htmx, «Показать ещё») блок не оживает.**
Модули запускаются при старте. **[кит]** — `createApp({ watch: true })` (по умолчанию) следит
за DOM и запускает модули в новом контенте сам. Если выключили — `app.mount(newNode)`.

**После удаления блока в консоли ошибки / обработчики продолжают срабатывать.**
Модуль не убрал за собой. Каждый `addEventListener`, `gsap.ticker.add`, `ScrollTrigger`,
`setInterval` — сразу в `createDisposer` (`d.listen(...)`, `d.add(...)`), а `destroy: d.dispose`.

**Настройка из атрибута не применяется.**
Ключ должен быть в `DEFAULTS` модуля, атрибут — `data-<модуль>-<ключ-через-дефис>`.
**[кит]** — на неизвестный атрибут будет предупреждение. `data-x-enabled="false"` — это `false`,
а не `true` (частый баг самописного парсинга, в ките закрыт).

## Анимации, GSAP, скролл

**Анимация на скролле срабатывает не там (раньше/позже).**
ScrollTrigger измерил страницу до загрузки картинок/шрифтов или до раскрытия аккордеона.
**[кит]** — `createApp` пересчитывает позиции после загрузки шрифтов и при любом изменении
высоты страницы. Своим картинкам задавайте `width`/`height` — тогда высота известна сразу.

**Элементы с `data-reveal` не появляются вообще.**
Нет `data-module="reveal"` на них или на предке. CSS прячет `[data-reveal]` до запуска модуля;
страховка — через 3 с всё покажется само **[кит]**. Если видите появление ровно через 3 секунды —
модуль не подключён.

**Перед анимацией видна «вспышка» исходного состояния.**
JS запустился позже первой отрисовки. **[кит]** — класс `.js` ставится инлайн-скриптом в `<head>`,
а CSS заранее прячет анимируемое.

**SplitText: строки «рвутся» или переносятся не так после загрузки шрифта.**
Текст разбит до загрузки шрифта. **[кит]** — `autoSplit: true` разбивает заново после шрифта
и при изменении ширины. Хвосты букв (у, р, д) обрезаются маской строки — **[кит]** запас снизу.

**Анимации на мобилке дёргаются/пины «прыгают» при скролле.**
Появление/скрытие адресной строки меняет высоту окна, ScrollTrigger всё пересчитывает.
**[кит]** — `ScrollTrigger.config({ ignoreMobileResize: true })`.

**Плавный скролл: колесо в модалке/меню/таблице крутит страницу.**
Добавьте блоку со своей прокруткой `data-lenis-prevent`.

**Плавный скролл: якорная ссылка уезжает под шапку.**
**[кит]** — смещение берётся из `--header-height`, её пишет модуль `sticky-header`.
Без этого модуля задайте `--header-height` в CSS.

**После перехода на другую страницу (React) анимации на месте старой страницы.**
ScrollTrigger не пересчитан, прокрутка не сброшена. **[кит]** — `useRouteReset` в `App.jsx`.

**Анимация тормозит.**
Анимируйте только `transform` и `opacity` (не `top/left/width/height/box-shadow`). Проверьте
FPS в dev-панели. Тяжёлый `filter: blur()` и большие `box-shadow` на анимируемых элементах —
главные подозреваемые.

**Пользователь с «уменьшением движения» видит всю анимацию.**
Каждый модуль кита проверяет `ctx.reduced`. Свои анимации — тоже: `if (ctx.reduced) return`.

**Магнитная кнопка (или любой эффект на quickTo) работает только в первый раз.**
Другой твин с `overwrite` на те же свойства (возврат на место, анимация появления) убил
твины `quickTo`, пока они ещё шли, — дальнейшие вызовы quickTo ничего не двигают.
Создавайте quickTo заново при каждом начале взаимодействия. **[кит]** — так сделано в `magnetic`.

## Формы

**Форма отправляется дважды (две заявки).**
Двойной клик. **[кит]** — кнопка блокируется на время запроса.

**После `reset()` поля красные, кастомный селект показывает старое значение.**
**[кит]** — ошибки чистятся, полям отправляется `change`.

**Ошибка «пароли не совпадают» не исчезает, хотя исправили.**
Исправили первое поле, а проверялось только второе. **[кит]** — при вводе перепроверяются все
поля, на которых висит ошибка.

**Ошибка от сервера («e-mail занят») пропадает, если кликнуть мимо.**
**[кит]** — ошибка, пришедшая с сервера, держится, пока значение поля не изменят.

**`minlength` не срабатывает на автозаполненном поле.**
Браузер проверяет длину только для текста, введённого вручную. **[кит]** — длина проверяется сами.

**Маска: курсор прыгает в конец при правке середины / Backspace «застревает» на дефисе.**
**[кит]** — см. `kit/js/form/mask.js`, оба случая закрыты и покрыты тестами.

**Вставка номера «8 (912) …» превращается в «+7 (891) …».**
**[кит]** — у 11-значного номера первая 7/8 считается кодом страны.

**В FormData нет неотмеченного чекбокса / файлы потерялись после второго выбора.**
FormData пропускает неотмеченные чекбоксы — используйте `formValues()` **[кит]**.
Второй выбор файлов заменяет первый — так устроен `<input type=file>`; **[кит]** — модуль
`file-upload` добавляет файлы к списку.

**Браузер открыл перетащенный файл вместо сайта.**
Промахнулись мимо зоны загрузки. **[кит]** — пока на странице есть `file-upload`, drop по окну гасится.

**Форма собирает имя/телефон — что нужно по закону.**
152-ФЗ: согласие на обработку (чекбокс, `partials/consent.html`) и страница политики
(`privacy.html`). Текст политики даёт заказчик.

## Модалки, меню, табы

**Модалка не открывается кнопкой.**
У кнопки `data-dialog-open="id"`, у `<dialog>` — тот же `id` и `data-module="dialog"`. Модуль
ставится на `<dialog>`, а не на `div`.

**Модалка открывается сама при загрузке.**
В адресе остался `#id-модалки` — так и задумано (ссылка на открытое окно). Не хотите —
`data-dialog-hash="false"`.

**«Назад» на телефоне уводит со страницы вместо закрытия модалки.**
**[кит]** — открытие добавляет запись в историю, «Назад» закрывает окно.

**Открыли меню на телефоне, повернули экран — меню пропало, а страница не крутится.**
**[кит]** — меню закрывается само, когда экран становится шире `closeAbove`.

**Tab уводит в ссылки скрытого меню / закрытого аккордеона.**
**[кит]** — скрытые панели получают `inert`.

**Две группы табов на странице «переключают друг друга» в адресе.**
У обеих параметр по умолчанию `tab`. Дайте корню `id` или `data-tabs-param="faq"` —
**[кит]** предупредит в консоли.

## Картинки, видео, шрифты

**Контент «прыгает» при загрузке картинок (плохой CLS в Lighthouse).**
У `<img>` нет `width` и `height` (или `aspect-ratio`). Браузер не знает высоту заранее.
Dev-панель → **Сдвиги (CLS)** покажет, что прыгает.

**Фоновое видео не запускается на iPhone.**
Нужны `muted` и `playsinline`. **[кит]** — `lazy-video` ставит их сам.

**`Uncaught (in promise) DOMException: play() failed`.**
Браузер запретил автозапуск. **[кит]** — ошибка ловится, остаётся постер.

**Шрифт «мигает» (сначала системный, потом свой).**
Это `font-display: swap` — правильное поведение. Чтобы сократить: подключите шрифт через
`@fontsource` или `<link rel="preload" as="font" type="font/woff2" crossorigin>` для основного
начертания и подберите похожий запасной шрифт.

## React

**Модуль кита в React срабатывает дважды / двойные точки у слайдера.**
StrictMode в разработке монтирует компоненты дважды. **[кит]** — `useModule` и модули к этому
готовы. Если пишете свой модуль — `destroy` обязан убирать всё.

**Модуль перезапускается на каждый рендер.**
В опции передан объект/функция, созданные внутри компонента: `useModule(form, { schema: s.object(…) })`.
Вынесите схему/функцию за пределы компонента или в `useMemo`/`useCallback`.

**React «затирает» aria-expanded / hidden, которые ставит модуль.**
Вы задали тот же атрибут в JSX. Не пишите в JSX то, чем управляет модуль.

**Поменялся список слайдов/пунктов, а модуль показывает старые.**
Модуль читает разметку при запуске. Перезапустите через `key`: `<Slider key={items.length}>`.

**`window is not defined` (Next.js, SSR).**
Код с `window`/`document` выполнился на сервере. Модули кита запускаются в `useEffect` — это
безопасно; свой код — тоже в `useEffect`, хуки кита SSR-безопасны.

## Языки и TypeScript

**Вместо текста на странице видно `hero.title`.**
Нет перевода для этого ключа (в разработке — предупреждение в консоли). Добавьте ключ в словарь
языка (`addMessages` или `src/i18n/ui.ts` в Astro).

**Английская версия не находится в поиске.**
Язык переключается скриптом — поисковик видит только исходный. Для сайтов — отдельные адреса
(`/en/`) и `hreflang`: стартер astro делает это сам.

**Ошибки форм на английской странице — по-русски.**
У `<html>` нет `lang="en"`. Тексты кита выбираются по нему.

**`npm i typescript-eslint` падает с ERESOLVE.**
Стоит TypeScript 7 — линтер его пока не поддерживает. Оставьте 6.x ([typescript.md](typescript.md)).

**Кастомный селект: список обрезан или под соседним блоком.**
**[кит]** — список открывается в верхнем слое браузера (Popover API). Если всё же обрезан —
браузер без Popover API (до 2023 года); помогает `z-index` у `.select__dropdown`.

## Тесты

**`matchMedia is not a function`, `IntersectionObserver is not defined`.**
В jsdom их нет. **[кит]** — заглушки в `test/setup.js`; `setMedia({...})` и
`triggerIntersect(el)` — управлять ими из теста.

**Размеры элементов в тесте = 0.**
jsdom не считает вёрстку. Используйте `setSize(el, { width, height })` из `test/helpers.js`
или тестируйте логику (чистые функции), а размеры — в браузере.

**Тест «утекает» в соседний (чужой хеш в адресе, открытые тосты).**
**[кит]** — после каждого теста документ, адрес и медиа сбрасываются (`test/setup.js`).

## Dev-инструменты

**Панели нет.**
Она только в `npm run dev`. Кнопка ⚙ — слева внизу, или Shift+Alt+K.

**Сетка/макет остались включёнными после перезагрузки.**
Состояние панели запоминается (localStorage `kit-devtools`) — так удобнее при вёрстке. Выключите
галочку или очистите хранилище.

**Мок-API отвечает 404.**
Нет файла `mocks/<путь>.js` для `/api/<путь>` — текст ответа подскажет, какой файл нужен.
Моки работают только в `npm run dev`; на проде запрос уходит на настоящий сервер.
