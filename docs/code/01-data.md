Везде: 270 квартир в шахматке, каталоге, на страницах квартир. Цены, статусы («свободна»,

## Зачем генерировать и почему «с зерном»

В настоящем проекте квартиры приходят из CRM застройщика. Здесь их нет — значит, их надо
придумать. `Math.random()` не подходит: при **каждой сборке** цены и статусы были бы новыми, а
человек, сохранивший ссылку на «двушку за 9,5 млн», увидел бы там квартиру за 12.

Генератор **с зерном** (seed) — «случайные» числа, которые при одном и том же зерне всегда одни и
те же. Выглядит случайно, повторяется точно.

## Код по частям

### mulberry32

```ts
export function seeded(seed: number) {
  let t = seed >>> 0
  return () => {
    t = (t + 0x6d2b79f5) >>> 0
    let r = Math.imul(t ^ (t >>> 15), 1 | t)
    r = (r + Math.imul(r ^ (r >>> 7), 61 | r)) ^ r
    return ((r ^ (r >>> 14)) >>> 0) / 4294967296
  }
}
```

Разбираться в каждом сдвиге не нужно — это известный маленький генератор (mulberry32). Важно
устройство:

- `seeded(2027)` возвращает **функцию**; каждый её вызов — следующее число от 0 до 1, как у
  `Math.random()`.
- Состояние `t` живёт в замыкании: два генератора с разными зёрнами не мешают друг другу.
- `>>> 0` — привести к беззнаковому 32-битному целому; `Math.imul` — умножение 32-битных целых
  без потери точности.
- Деление на `2³²` переводит целое в дробь 0…1.

```ts
const a = seeded(7), b = seeded(7)
a() === b()   // true — то же зерно, та же последовательность
```

### Типовой этаж

```ts
const FLOOR_PLAN = [
  { layout: 'three', rooms: 3, area: [78, 86], kitchen: 14 },
  { layout: 'one', rooms: 1, area: [36, 41], kitchen: 10 },

const BASE_PRICE = [210_000, 235_000, 262_000]   // ₽/м² по башням — у реки дороже
```

Случайность — **внутри разумных рамок**: площадь трёшки от 78 до 86 м², а не «от 0 до 1000».
Так данные выглядят правдоподобно, и фильтры показывают осмысленные результаты.
