# dialog

Модальное окно на нативном <dialog>; открывается кнопкой, ссылкой #id и адресом.

|                 |                                     |
| --------------- | ----------------------------------- |
| Подключение     | `data-module="dialog"`              |
| Настройки       | closeOnBackdrop, closeTimeout, hash |
| API (экземпляр) | open(), close(), isOpen             |
| События         | dialog:open, dialog:close           |

**Что учтено:** Блокировка прокрутки, анимация закрытия со страховкой, «Назад» закрывает окно, возврат фокуса.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#dialog),
подробности и «почему так» — комментарий в начале `index.js`.
