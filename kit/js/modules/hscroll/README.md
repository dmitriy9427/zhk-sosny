# hscroll

Горизонтальная лента, которую двигает вертикальная прокрутка.

|                 |                         |
| --------------- | ----------------------- |
| Подключение     | `data-module="hscroll"` |
| Настройки       | min (брейкпоинт), scrub |
| API (экземпляр) | —                       |
| События         | —                       |

**Что учтено:** containerAnimation для эффектов карточек; пересчёт при ресайзе; на мобилке — обычная лента.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#hscroll),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
