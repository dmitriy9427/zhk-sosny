# mask

Маска на отдельном поле (в форме маски включаются сами).

|                 |                                                  |
| --------------- | ------------------------------------------------ |
| Подключение     | `data-module="mask"`                             |
| Настройки       | data-mask, data-mask-pattern, data-mask-decimals |
| API (экземпляр) | mask                                             |
| События         | —                                                |

**Что учтено:** Курсор не прыгает; Backspace не застревает на дефисе; вставка «8…» для телефона.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#mask),
подробности и «почему так» — комментарий в начале `index.js`.
