# flip-filter

Фильтр карточек по категориям с Flip-анимацией.

|                 |                             |
| --------------- | --------------------------- |
| Подключение     | `data-module="flip-filter"` |
| Настройки       | param                       |
| API (экземпляр) | apply(filter), filter       |
| События         | —                           |

**Что учтено:** Страница не прыгает; фильтр в адресе; несколько категорий у карточки.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#flip-filter),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
