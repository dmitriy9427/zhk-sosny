# swiper

Swiper с пресетами и исправлениями частых проблем.

|                 |                                                                   |
| --------------- | ----------------------------------------------------------------- |
| Подключение     | `data-module="swiper"`                                            |
| Настройки       | preset, options (JSON), breakpoints (по именам), controls, thumbs |
| API (экземпляр) | swiper, thumbs                                                    |
| События         | swiper:change                                                     |

**Что учтено:** Стрелки вне слайдера; скрытые контейнеры; loop при малом числе слайдов; автопрокрутка вне экрана; ширина во flex/grid; русские подписи.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#swiper),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
