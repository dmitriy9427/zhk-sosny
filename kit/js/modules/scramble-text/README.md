# scramble-text

Текст «расшифровывается» при появлении или наведении.

|                 |                               |
| --------------- | ----------------------------- |
| Подключение     | `data-module="scramble-text"` |
| Настройки       | on, chars, duration           |
| API (экземпляр) | play()                        |
| События         | —                             |

**Что учтено:** Ширина не дёргается; aria-label с итоговым текстом.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#scramble-text),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
