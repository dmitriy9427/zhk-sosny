# theme-switch

Переключатель светлой/тёмной темы.

|                 |                              |
| --------------- | ---------------------------- |
| Подключение     | `data-module="theme-switch"` |
| Настройки       | —                            |
| API (экземпляр) | —                            |
| События         | theme:change                 |

**Что учтено:** Тема применяется инлайн-скриптом в <head> до отрисовки — без «вспышки».

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#theme-switch),
подробности и «почему так» — комментарий в начале `index.js`.
