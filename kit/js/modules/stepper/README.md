# stepper

Поле количества − 1 +.

|                 |                           |
| --------------- | ------------------------- |
| Подключение     | `data-module="stepper"`   |
| Настройки       | — (min/max/step из input) |
| API (экземпляр) | increment(), decrement()  |
| События         | input, change на поле     |

**Что учтено:** Без 0.30000000004; кнопки блокируются на краях; ручной ввод приводится к диапазону.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#stepper),
подробности и «почему так» — комментарий в начале `index.js`.
