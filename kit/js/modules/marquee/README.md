# marquee

Бесконечная бегущая строка.

|                 |                              |
| --------------- | ---------------------------- |
| Подключение     | `data-module="marquee"`      |
| Настройки       | speed, reverse, pauseOnHover |
| API (экземпляр) | play(), pause()              |
| События         | —                            |

**Что учтено:** Без рывка при заворачивании; клоны aria-hidden + inert; пауза вне экрана; скорость не зависит от FPS.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#marquee),
подробности и «почему так» — комментарий в начале `index.js`.
