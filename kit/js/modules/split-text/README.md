# split-text

Заголовок появляется по строкам/словам/буквам (SplitText).

|                 |                                |
| --------------- | ------------------------------ |
| Подключение     | `data-module="split-text"`     |
| Настройки       | type, start, stagger, duration |
| API (экземпляр) | split                          |
| События         | —                              |

**Что учтено:** autoSplit после загрузки шрифта; запас под хвосты букв; revert в destroy.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#split-text),
подробности и «почему так» — комментарий в начале `index.js`.
