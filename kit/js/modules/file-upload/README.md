# file-upload

Загрузка файлов: перетаскивание, превью, удаление, лимиты.

|                 |                                         |
| --------------- | --------------------------------------- |
| Подключение     | `data-module="file-upload"`             |
| Настройки       | maxFiles, maxSize (МБ), accept, preview |
| API (экземпляр) | files, add(files), clear()              |
| События         | file-upload:change                      |

**Что учтено:** Повторный выбор добавляет, а не заменяет; освобождение превью (revokeObjectURL); drop мимо зоны не открывает файл.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#file-upload),
подробности и «почему так» — комментарий в начале `index.js`.
