# slider

Карусель на CSS scroll-snap: стрелки, точки, перетаскивание мышью, автопрокрутка.

|                 |                                |
| --------------- | ------------------------------ |
| Подключение     | `data-module="slider"`         |
| Настройки       | autoplay, dotLabel             |
| API (экземпляр) | goTo(i), next(), prev(), index |
| События         | slider:change                  |

**Что учтено:** Клик после перетаскивания гасится; snap выключается на время drag; автопрокрутка на паузе при наведении/фокусе/вне экрана.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#slider),
подробности и «почему так» — комментарий в начале `index.js`.
