# lazy-video

Фоновое видео: грузится у экрана, играет только видимым.

|                 |                            |
| --------------- | -------------------------- |
| Подключение     | `data-module="lazy-video"` |
| Настройки       | —                          |
| API (экземпляр) | play(), pause()            |
| События         | —                          |

**Что учтено:** muted + playsinline для автозапуска на iOS; ошибка play() не сыпется в консоль.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#lazy-video),
подробности и «почему так» — комментарий в начале `index.js`.
