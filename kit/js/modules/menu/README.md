# menu

Мобильное меню (модуль на кнопке-бургере).

|                 |                                           |
| --------------- | ----------------------------------------- |
| Подключение     | `data-module="menu"`                      |
| Настройки       | target, closeAbove, labelOpen, labelClose |
| API (экземпляр) | open(), close(), toggle(), isOpen         |
| События         | menu:toggle (DOM и шина)                  |

**Что учтено:** Закрывается при расширении экрана, по Esc и клику по ссылке; inert; удержание фокуса.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#menu),
подробности и «почему так» — комментарий в начале `index.js`.
