# lang-switch

Переключатель языка: ссылки на языковые версии (сайты) или кнопки data-lang (смена на лету).

|                 |                             |
| --------------- | --------------------------- |
| Подключение     | `data-module="lang-switch"` |
| Настройки       | —                           |
| API (экземпляр) | —                           |
| События         | locale:change (document)    |

**Что учтено:** Помечает текущий язык (aria-current / aria-pressed); выбор запоминается.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#lang-switch),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
