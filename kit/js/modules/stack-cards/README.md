# stack-cards

Карточки стопкой при прокрутке (sticky + scrub).

|                 |                             |
| --------------- | --------------------------- |
| Подключение     | `data-module="stack-cards"` |
| Настройки       | scale, dim                  |
| API (экземпляр) | —                           |
| События         | —                           |

**Что учтено:** Предупреждение, если sticky не сработает из-за overflow у предка.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#stack-cards),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
