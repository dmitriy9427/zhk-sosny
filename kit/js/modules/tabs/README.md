# tabs

Вкладки; открытая вкладка хранится в адресе (?tab=…).

|                 |                      |
| --------------- | -------------------- |
| Подключение     | `data-module="tabs"` |
| Настройки       | active, url, param   |
| API (экземпляр) | select(i), index     |
| События         | tabs:change          |

**Что учтено:** replaceState — история не засоряется; popstate восстанавливает вкладку; предупреждение при одинаковых параметрах.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#tabs),
подробности и «почему так» — комментарий в начале `index.js`.
