# sticky-header

Шапка прячется при прокрутке вниз, пишет --header-height.

|                 |                               |
| --------------- | ----------------------------- |
| Подключение     | `data-module="sticky-header"` |
| Настройки       | hide, offset, tolerance       |
| API (экземпляр) | show()                        |
| События         | —                             |

**Что учтено:** Не прячется при открытом меню и при фокусе внутри; порог против дрожания.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#sticky-header),
подробности и «почему так» — комментарий в начале `index.js`.
