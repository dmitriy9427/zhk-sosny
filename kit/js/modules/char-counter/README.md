# char-counter

Счётчик символов «120 / 500».

|                 |                              |
| --------------- | ---------------------------- |
| Подключение     | `data-module="char-counter"` |
| Настройки       | max                          |
| API (экземпляр) | update()                     |
| События         | —                            |

**Что учтено:** Скринридер слышит остаток только у лимита (≤ 10%).

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#char-counter),
подробности и «почему так» — комментарий в начале `index.js`.
