# kit — общий кит

Копируется в каждый проект (`npm run create`). Ничего не знает о конкретном сайте.

| Папка                    | Что внутри                                                                  |
| ------------------------ | --------------------------------------------------------------------------- |
| [js/core](js/core)       | ядро: запуск модулей, уборка, шина событий, опции, окружение, скролл, адрес |
| [js/modules](js/modules) | готовые модули (`data-module="…"`)                                          |
| [js/form](js/form)       | схемы проверки, маски, значения форм                                        |
| [scss](scss)             | настройки, функции, миксины, базовые стили, стили компонентов               |
| [react](react)           | `useModule`, `KitProvider`, хуки (только в React-проектах)                  |
| [devtools](devtools)     | dev-панель — только в разработке                                            |
| [vite](vite)             | Vite-плагины: include, страницы, мок-API, защита прода                      |

Править в проекте можно, но обновление кита (`--update`) перезапишет правки —
см. [docs/structure.md](../docs/structure.md#можно-ли-править-kit-в-проекте).
