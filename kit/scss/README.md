# scss — стили

| Путь           | Что внутри                                                                          | Выводит CSS? |
| -------------- | ----------------------------------------------------------------------------------- | ------------ |
| `_config.scss` | все настройки с `!default`: цвета, тёмная тема, брейкпоинты, шрифты, сетка, z-index | нет          |
| `abstracts/`   | `_functions.scss` (rem, fluid, color, z, bp…), `_mixins.scss` (up/down, hover…)     | нет          |
| `base/`        | переменные `:root`, сброс, типографика, доступность, Lenis, утилиты                 | да           |
| `components/`  | кнопки, аккордеон, табы, модалка, меню, шапка, слайдер, поля, мелочи                | да           |
| `_index.scss`  | base + components — подключается один раз в `main.scss`                             | да           |

Ненужный компонент — уберите строку из `components/_index.scss`.
Руководство — [docs/styles.md](../../docs/styles.md). Тесты — `scss.test.js`
(компиляция, настройки, понятные ошибки, совпадение брейкпоинтов с JS).
